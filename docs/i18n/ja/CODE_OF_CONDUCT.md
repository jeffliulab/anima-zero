## 私たちの誓い

メンバー・コントリビューター・メンテナーである私たちは、年齢、体格、目に見えるかどうかを問わない
障害、民族、性自認と性表現、経験の度合い、学歴、社会経済的地位、国籍、外見、人種、宗教、
性的指向とアイデンティティにかかわらず、このプロジェクトとそのコミュニティへの参加を
すべての人にとってハラスメントのない体験にすることを誓います。

私たちは、開かれた、歓迎的で、多様性があり、包摂的で健全なコミュニティに寄与するかたちで
行動し、交流することを誓います。

## 私たちの基準

**望ましい振る舞い**：思いやりと共感を示すこと。異なる意見や経験を尊重すること。
建設的なフィードバックを与え、また快く受け入れること。自分の誤りに責任を持ち、影響を受けた人に
謝罪し、その経験から学ぶこと。コミュニティ全体にとって何が最善かに目を向けること。

**望ましくない振る舞い**：性的な言葉や表現、およびあらゆる形の性的な関心や誘い。
荒らし行為、侮辱的・軽蔑的なコメント、個人攻撃や政治的攻撃。公私を問わないハラスメント。
物理的な住所やメールアドレスなど、他者の私的な情報を明確な許可なく公開すること。
その他、職業上の場において不適切と合理的にみなされうる行為。

## 執行

メンテナーはこれらの基準を明確にし、執行する責任を負います。また、不適切・脅迫的・攻撃的、
あるいは有害だと判断した行為に対して、適切かつ公正な是正措置をとります。

メンテナーは、この行動規範に沿わないコメント・コミット・コード・issue・その他の貢献を
削除、編集、または拒否する権利と責任を持ち、必要に応じてその判断の理由を説明します。

## 適用範囲

この行動規範は、すべてのコミュニティの場において適用されます。また、個人が公の場で
コミュニティを公式に代表している場合にも適用されます。

## 報告

虐待的・ハラスメント的、その他受け入れがたい行為は、メンテナーにメールで報告してください。
アドレスは `pyproject.toml` の `authors` にあります。すべての申し立ては速やかかつ公正に
確認・調査され、報告者のプライバシーと安全は尊重されます。

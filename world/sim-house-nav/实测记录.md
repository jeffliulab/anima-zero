# sim-house-nav 实测记录

这个世界**跑通了什么**——每条都有可复核的证据（会话 id + 感知图 + `/status` 真值）。

> ⚠️ 这是一份**成功案例**清单，不是全部结果。同批实验里有失败的、也有没收尾的，
> 完整成绩与失败分析在开发日志（`anima-zero-个人用详细开发日志/v1.x/v1.0-开发日志.md`）。
> 拿这份文件当"这个世界能干什么"的证据，别当"这个世界干什么都行"的证明。

**口径**：大脑 = gpt-5.5；`步` = 一轮里「看→想→动」转了几圈（＝感知图张数）；
真值取自世界的 `/status`（上帝视角，⛔ 绝不进大脑的观测）。
判定标准 = 「看见就算到」：它能清楚看见目标房间、说得出看到了哪几件标志物就算完成，
**且我逐张渲图核对过它当时实际看到的画面**——它说的和画面里有的对得上才记为成功。

## 二、两种身体都能在屋里真的走

**不是瞬移**：机器人身上跑的是训练出来的速度条件式步态策略，导航原语被翻译成速度指令
`(vx, vy, wz)` 喂给它，腿真的迈出去。世界一边走一边量，**实测位移/转角达标才停**。

### 四足（`test_walk.py`）

| 动作 | 命令 | 实测 |
|---|---|---|
| 直线前进 | vx=0.6 m/s | 达成 76%，不摔 |
| 原地左转 | wz=0.8 rad/s | 4 秒转 99°，位置漂移 0.09 m，不摔 |

### 人形（屋内闭环实测）

```
出生（玄关）→ turn_left(90)   → 向左转了 94 度，顺带往前挪了 0.75 米
             → move_forward(2) → 走了 1.27 米就停住了——正前方只剩 0.60 米（撞前刹车）
             → turn_right(90)  → 向右转了 92 度，顺带往前挪了 0.64 米
             → move_forward(1.5)→ 走了 1.65 米，刹车停住
全程不摔，倾角 <2°
```

⚠️ **人形不能原地转**——站着不动时策略选择站住省力（实测 8 秒只转 3.8°）。
所以它的转弯原语带 0.3 m/s 前进速度，转 90° 会往前挪 0.6~0.8 米，**和真人转身一样**；
世界把这个位移如实报给大脑，不假装原地没动。
背后的训练实验见 locomotion 仓 `experiments/1-locomotion/14-g1-29dof-velocity-turn/`。

## 三、激光测距 + 撞前刹车（`test_lidar.py` 四项全过）

| 验收项 | 结果 |
|---|---|
| 射线没打到机器人自己 | ✅ 八向读数均 > 0.30 m（不过滤的话正前方永远读 0.127 m） |
| 读数跟着朝向转 | ✅ 原地转 91° 后，八个方向 **8/8** 整体轮转一格 |
| 撞前刹车 | ✅ 走 2.69 m 后在离墙 0.58 m 处停住，不摔；再往前走如实回「这个朝向走不了」 |
| 观测红线 | ✅ state 只有 `heading_deg` / `clearance_m` / `front_cone_m` / `fallen` / `last_action`，**没有坐标、没有房间名** |

**一个真实现象**（也是为什么给大脑两个距离字段）：机器人站在窄口前，
`clearance_m["正前"] = 8.00 m`（中心那条射线穿过去了），而 `front_cone_m = 0.46 m`
（肩膀宽度范围内最近的东西）。两个数都对、含义不同，所以两个都给，并说清各自语义。

## 四、换身体（AWI 世界配置通道）

一条 HTTP 请求换掉整个身体，大脑自动跟上：

```bash
curl -s -X POST localhost:8000/api/worlds/sim-house-nav/config \
     -H 'Content-Type: application/json' -d '{"key":"body","value":"g1"}'
# → {"ok": true, "message": "已换成人形机器人（宇树 G1，29 自由度），放回出生点。"}
```

换完立刻可以核到：

- 世界重建成人形、回到出生点；
- 大脑**自动重新握手**（改配置后后端主动丢缓存，见 `server.py` 的 `set_world_config`）；
- 工具说明**自动变成人形的口径**——`turn_left` 从「原地转」变成
  「⚠️ 这台机器人**不能原地转**…转弯时会顺带往前走一小段」。

⛔ 这条通道**只读给大脑**：大脑被告知"你现在是什么身体"，但没有改它的工具——
换身体是人在开跑前做的场地配置。

## 五、第三视角跟拍（⛔ 只给人看）

从斜后上方跟着机器人，能看见它**正走向**哪儿；被家具挡住会自动把镜头拉近。
机位按机器人分（狗退 1.6 m 抬 0.7 m、人形退 2.6 m 抬 1.7 m）。

⛔ **这一路 ANIMA 绝对看不到**：`/streams` 里标着 `awi: false`，网页把它摆在单独一块、
标明"只有你看得到"。红线由 `anima-zero/tests/test_third_person.py` 四条测试钉着，
反向验证过（故意去掉标记，测试立刻红）。

## 怎么自己复现

```bash
# 起世界（默认四足；换人形加 HOUSENAV_ROBOT=g1，或起来后走 /config）
cd anima-zero/world/sim-house-nav && ./.venv/bin/uvicorn server:app --port 8112

# 两个无头自测（各几十秒，会真起 MuJoCo）
./.venv/bin/python test_walk.py
./.venv/bin/python test_lidar.py

# 端到端一轮（要起后端 :8000，LLM key 走 anima-zero/.env）
cd anima-zero && ./.venv/bin/python -m anima.dev_turn \
    --world sim-house-nav --say "去厨房" --brain gpt-5.5

# 核真值（⚠️ 只给人看）
curl -s localhost:8112/status | python3 -m json.tool
```
